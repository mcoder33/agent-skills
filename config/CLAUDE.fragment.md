## Навыки codex-skills

Навыки установлены плагином `codex-skills` из маркетплейса `codex-skills` и вызываются через инструмент Skill по полному имени `codex-skills:<навык>`.

- Для содержательных объяснений, исследований, планов и отчётов применяй `codex-skills:clear-communication` как постоянное руководство; загрузи один раз за сессию и возвращайся при необходимости. HTML, презентации и отдельные визуальные артефакты создавай только по запросу.
- Во всех задачах постепенно подстраивай тон, подробность и темп по `codex-skills:adaptive-dialogue`. Прямые текущие поправки важнее предположений; молчание не означает согласия. Предпочтения сохраняй только по правилам уже разрешённой памяти.
- Для совместного исследования сложной или неясной проблемы используй `codex-skills:dialogue-explore`, для совместной проверки предложенного плана — `codex-skills:dialogue-validate`. Это не включает интервью для простых вопросов, конкретных поручений или явно запрошенной автономной работы.
