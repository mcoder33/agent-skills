# Спросить Claude

Передай Claude текст после `$claude` или прямой просьбы «спроси у Клода». Сохрани формулировку пользователя. Если «это» или «предыдущий вариант» ссылается на контекст чата, приложи нужный фрагмент. Для вопроса с заданным форматом ответа передай и это требование.

Вызови интерактивный Claude через [клиент StealthBox из соседнего навыка orchestrate](../orchestrate/scripts/stealthbox_claude.py). Вызов `$claude` сам выбирает исполнителя. Для запуска, проверки статуса и закрытия используй [инструкцию клиента](../orchestrate/references/stealthbox-claude.md). Пути в её примерах отсчитываются от каталога `orchestrate`.

- **Общий вопрос.** Передай `--project .`. Это корень рабочей области на ВМ. Для обычного разговора достаточно текста вопроса.
- **Вопрос о проекте.** Используй указанный пользователем проект или текущий checkout относительно `workspace.local_root` выбранного профиля. Claude читает копию на ВМ. Если задача зависит от локального изменения, приложи нужный diff или фрагмент из разрешённого контекста.
- **Уточнение.** Сохрани идентификатор задачи в контексте этого чата. Продолжай тот же диалог через `reply`, пока окно открыто, или `resume` после его закрытия. Для независимого вопроса создай новую задачу.

Дождись ответа Claude и верни его пользователю, сохранив язык, формулировки и разметку. Если Claude запросил уточнение, передай его вопрос и сохрани диалог для продолжения. При завершённом ответе сохрани результат и закрой своё окно через `finish` с принятым `turn`. Если получить ответ не удалось, сообщи фактическую причину.
