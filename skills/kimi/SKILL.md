# Спросить Kimi

Передай Kimi вопрос в формулировке пользователя. Если он ссылается на «код выше» или «этот план», приложи относящийся к вопросу фрагмент. Запускай [клиент](scripts/ask_kimi.py) из установленного навыка через Python 3. Он общается с локальным `kimi acp`, а запрос обрабатывает провайдер текущего профиля Kimi Code.

```sh
python3 scripts/ask_kimi.py --model k3.1-pro --effort low <<'QUESTION'
Почему при пагинации сортировка должна быть стабильной?
QUESTION
```

Для обычного вопроса достаточно stdin. Для вопроса о локальном проекте укажи его каталог через `--cwd`. Модель и уровень рассуждения передавай независимо и только по выбору пользователя. Клиент сверяет параметры с вариантами, которые предлагает установленная Kimi для этой модели. Имя `k3.1-pro` в примере — короткая форма настроенного псевдонима. В новом диалоге без параметров действует текущий профиль.

Дождись завершения процесса, сохрани `session_id` и `cwd` из JSON в контексте разговора и верни пользователю поле `answer`, сохранив язык и разметку. Если пользователь уточняет предыдущий вопрос, передай новый текст на stdin с `--resume <session_id> --cwd <прежний каталог>`. Для продолжения можно явно выбрать другую доступную модель или глубину.

При прерывании используй идентификатор сессии из stderr, чтобы не запускать повторно уже отправленное задание. Если Kimi запросила разрешение на действие, клиент прерывает ход и сообщает, что требовалось. Передай это сообщение пользователю. При ошибке входа или провайдера сообщи полученную ошибку.
