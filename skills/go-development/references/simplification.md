# Упрощение без потери контракта

Открывай при удалении защитных проверок, мёртвого кода, обёрток и тестовых входов.
Это рефакторинг: наблюдаемый контракт сохраняется, найденный дефект оформляется
отдельным изменением поведения.

## Проверка: лишняя или защитная

Решение принимай по всем callers и фактической проводке, а не по имени функции.
Проверка лишняя, когда её условие недостижимо или уже установлено на том же пути:

- значение создаёт только проверяющий конструктор, а поля типа неэкспортируемые;
  повторная проверка того же инварианта ниже по пути ничего не добавляет;
- сравниваются только константы: замени runtime-ошибку проверкой при компиляции
  или тестом;
- то же неизменное значение уже проверено на этом пути. Повтор не бесплатен,
  если проверка пишет лог, метрику или копирует данные;
- условие исключено единственной проводкой: consumer читает один топик,
  конфигурация проверена при загрузке, обязательный аргумент всегда передаётся.

Оставь проверку, которая:

- отделяет внешний вход, необязательную зависимость или конфигурацию;
- охраняет sentinel-соглашение, например «-1 — без лимита» от отрицательного остатка;
- задаёт порядок протокола, state machine, отмену или владение при конкурентности;
- делает `Close` безопасным для cleanup после частичной инициализации;
- закреплена тестом как отказ до эффектов внешнего контракта.

Тест, который проверял только невозможное состояние, удаляется вместе с проверкой.
Тест внешнего контракта сохраняется.

## Мёртвый код и обёртки

`unused` не видит экспортируемые символы, `unparam` находит постоянные аргументы
и результаты. Достижимость считай от `main`-пакетов штатным инструментом проекта
или чтением вызовов. Поиск по имени ненадёжен: фильтр строк с `func ` скрывает
вызовы внутри замыканий, а одноимённые методы разных типов сливаются.

Вызывающими считаются и внешние тестовые пакеты, и исполняемые fixture-программы:
они не видят методы из `_test.go` импортируемого пакета. Обёртку, которая только
подставляет значение по умолчанию и нужна лишь тестам, переноси в тест или вызывай
реализацию с явным значением. Цепочку переадресаций без собственного смысла
замени прямым вызовом.

Недостижимый из точек входа, но задокументированный юнит, доказательство или
исторический harness удаляет только владелец. Назови размер, связи с живым путём
и покрытие, которое исчезнет вместе с ним.
